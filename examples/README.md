# 示例作业（项目库演示用）

这里的代码是**故意写错的**，专门用来演示「AI 检测 / 生成注释 / 自动改错」三个功能。
每个文件开头都写明了留了哪些错误，可以自己先找一找，再点按钮对照 AI 的结论。

| 文件 | 语言 | 故意留的错误 |
| --- | --- | --- |
| `示例作业/bubble_sort.c` | C | 打印时循环多跑一轮（数组越界）；比较符号写反（排成从大到小） |
| `示例作业/score_stats.py` | Python | 平均分分母写成 `len(scores) + 1`；空列表时取 `scores[0]` 会崩 |
| `示例作业/ScoreManager.java` | Java | `getMax` 初始值取 0，全是负数时会返回错误结果 |

## 怎么用它

1. 双击 `start.bat` 启动服务；
2. 页面左侧「② 本地项目库」里会看到 `examples` 这个来源，点任一文件即可载入；
3. 依次点「AI 检测」「生成注释」「自动改错」看效果。

## 换成自己的作业

把自己写的 `.c` / `.h` / `.java` / `.py` 文件放进项目根目录下的 `data/library` 文件夹，
再点项目库标题右边的 ↻ 刷新即可。

也可以扫描自己平时放作业的文件夹：在 `.env` 里加一行（多个目录用逗号隔开）

```ini
LIBRARY__ROOTS=D:\我的作业, E:\课程代码
```

改完重启服务生效。出于安全考虑，**能被扫描的目录只能这样在后端配置**，
页面上没有任何地方可以指定任意路径，所以不用担心误读到系统文件。
